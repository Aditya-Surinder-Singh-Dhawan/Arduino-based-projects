1. Bluetooth Controlled Arduino RC Car

This project is a Bluetooth-controlled 4-wheel RC car built using an Arduino Uno, HC-05 Bluetooth module, L298N motor driver, and four DC geared motors.

The car can be controlled wirelessly using a Bluetooth-enabled smartphone. The Arduino receives commands from the HC-05 Bluetooth module and controls the motors through the L298N motor driver.

The car supports forward, backward, left, right, and stop commands. It uses an on-the-spot turning mechanism, where the wheels on opposite sides rotate in different directions, allowing the car to turn without needing a steering mechanism.

This project was built to explore the fundamentals of Arduino programming, Bluetooth communication, motor control, PWM, digital electronics, and basic robotics.


Features

- Wireless Bluetooth control
- Four-wheel drive
- Forward and backward movement
- Left and right on-the-spot turning
- Stop function
- PWM-based motor speed control
- Arduino-based control system
- HC-05 Bluetooth communication

2. Automatic Solar Tracker

This project is an automatic solar tracking system built using an Arduino Uno, two LDR (Light Dependent Resistor) modules, a servo motor, and a small solar panel.

The system automatically detects the direction of the stronger light source using the two LDR sensors. The Arduino compares the light intensity detected by both sensors and controls the servo motor to adjust the position of the solar panel toward the brighter source.

The goal of the project is to demonstrate how a solar panel can automatically change its orientation according to the position of the light source instead of remaining fixed in one direction.

This project was built to explore the fundamentals of Arduino programming, sensor-based automation, analog input, servo motor control, feedback systems, and basic solar-tracking concepts.


Features

- Automatic light detection
- Two LDR-based light sensors
- Servo-controlled panel movement
- Arduino-based control system
- Automatic adjustment toward the stronger light source
- Simple sensor feedback mechanism
- Demonstrates the basic principle of solar tracking

3. Basic Automated Robotic Arm

This project is a basic automated robotic arm built as a science exhibition project for the students of my school. The arm was designed using three motors, with each motor responsible for a different movement of the mechanism.

The first motor controls the base of the arm, allowing it to move from side to side. The second motor controls the arm's vertical movement, allowing it to lower and lift the hand. The third motor operates the gripping mechanism, allowing the arm to clasp and release an object.

The arm follows a programmed pick-and-place sequence. It first lowers the arm, closes the gripper to pick up an object, lifts it, and rotates the base toward the other side. The arm then lowers again and releases the object at the destination. The sequence repeats continuously, demonstrating an automated pick-and-place operation.

The project was created to demonstrate basic robotics and automation concepts in a simple and understandable way for a school science exhibition. It helped demonstrate how multiple motors can be coordinated to perform a complete mechanical task automatically.


Features

- Three-motor robotic arm
- Side-to-side base movement
- Automatic arm lifting and lowering
- Motor-controlled gripping mechanism
- Automated pick-and-place operation
- Sequential motor coordination
- Continuous operating cycle
- Designed for a school science exhibition
- Demonstrates basic robotics and automation
